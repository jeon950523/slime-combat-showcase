# Slime Combat Showcase · 슬라임은 먹고싶어

> 몸을 늘려 싸우고, 쓰러진 적을 포식해 성장하며, 침식된 지역을 돌파하는 **Unity 2D 횡스크롤 액션 RPG**.

현재는 작은 거점과 R1 필드, 지역 보스를 연결한 개발 시제품입니다. 이 페이지는 최신 기획 방향과 실제 Unity 구현 범위를 압축한 포트폴리오이며, 완성 게임이나 배포 빌드를 소개하는 페이지는 아닙니다.

## Current Direction / 현재 방향

좌우 이동·점프·높낮이가 있는 공간에서 적의 공격을 읽고 대응하는 직접 조작 액션을 중심으로 개발하고 있습니다. 기본 지역 탐험에는 강제 제한 시간이 없으며, **지역 보스 처치가 다음 지역 진행의 핵심 조건**입니다.

Hollow Knight / Dead Cells 계열에서는 횡스크롤 이동, 전투와 탐험의 연결, 공간 구성, 공격 예고와 전투 가독성의 방향을 참고합니다. 두 작품의 자산·캐릭터·맵·고유 시스템을 복제하는 것을 목표로 하지 않습니다.

Slime의 핵심은 젤리 몸의 탄성을 이용한 타격과 수동 포식입니다. 처치 이후에도 직접 먹는 행동으로 보상을 완성하고, 영구 레벨과 거점 연구를 다음 탐험으로 이어갑니다. 동물의 특징을 흡수한 폼은 같은 슬라임의 외형과 전투 성향을 확장하는 방향입니다.

## Core Loop / 핵심 흐름

```text
거점에서 준비
→ R1 필드 이동·점프·직접 전투
→ 쓰러진 적을 수동 포식 → 영구 XP·골드 획득
→ 지역 보스 도전·처치 → 진행 자격 저장
→ 승리 핵 포식 → 경험치 확정
→ 거점 귀환·연구 구매
→ 강화된 상태로 재출발 / 저장 후 안전한 거점에서 재개
```

첫 완성 목표는 거점 하나, 짧은 R1 필드 하나, 근접 일반 적 한 종류, 보스 한 종류로 이 흐름을 끝까지 플레이할 수 있게 만드는 것입니다.

## Combat Design / 전투 설계

- **몸 늘리기 타격**: 전방·위·공중 아래 방향으로 공격합니다. 기본 타격 중 이동과 점프 흐름을 유지하고, 아래 공격은 실제 명중 시 반동으로 연결됩니다.
- **처치와 포식의 분리**: 살아 있는 적은 타격으로 쓰러뜨리고, E 유지 입력으로 시체를 포식합니다. 현재 통합 시제품은 플레이어 중심 전방향 범위에서 여러 시체를 포식하며, 벽·지형 너머의 시체도 범위 안에서 처리합니다.
- **블루의 세 액티브**: A 파동, S 직선 젤리탄, D 몸통박치기를 구현했습니다. 몸통박치기는 첫 적이나 벽에서 멈추는 접근 공격이며 무적 기술이 아닙니다.
- **별도 회피**: Shift로 지상·공중 회피를 사용합니다. 짧은 무적, 충전 회복, 공격·스킬 취소 경계가 있으며 벽 통과를 막는 충돌 검사를 적용합니다.
- **읽고 대응하는 적**: 일반 적은 접근·예고·공격·후딜을 구분합니다. 보스는 일반 타격 경직으로 패턴을 무한 취소할 수 없게 구성했습니다.

현재 R1 보스 **침식된 뿌리 수호자**는 휩쓸기, 내려찍기·충격파, 발밑 뿌리 솟기의 세 패턴을 사용합니다. 노랑/빨강 예고는 패링 가능/방어 불가 분류를 나타내며, 색과 동작·범위 표현을 함께 사용합니다. 블루의 회피와 그린의 패링은 별도 동작입니다.

| 폼 | 전투 성향 | 현재 연결 범위 |
| --- | --- | --- |
| BLUE | 파동·원거리 젤리탄·몸통박치기 | R1 통합 씬에서 사용 |
| GREEN | 방어·패링 → 강화 게이지 → 근접 공격·도약 내려찍기 | 별도 전투 실험 씬 구현; 통합 폼 선택·해금 미연결 |
| RED | 빠른 공격·상처/출혈 → 파열·광폭화 | 별도 전투 실험 씬 구현; 통합 폼 선택·해금 미연결 |

전투 조절값은 CSV로 관리합니다. 현재 값은 시제품 검증용이며 최종 밸런스가 확정된 상태는 아닙니다.

## Movement / Exploration / Level Flow

좌우 방향키 이동과 Space 가변 점프를 기반으로 경사·높낮이·발판을 통과합니다. 점프 입력 버퍼, 가장자리 점프 유예(Coyote Time), 추적 카메라를 구현했고, 몸의 시각적 늘어남·착지 눌림과 실제 충돌 크기는 분리합니다.

맵은 유한한 구간으로 구성합니다. 명확한 주 경로와 짧은 전투 구간을 먼저 다듬고, 선택 경로·상자는 후속 탐험 요소로 검토합니다. 현재 통합 씬에서는 **거점 ↔ R1 필드 → 보스 전장**을 하나의 Unity 씬 안에서 구역·카메라·시작점 전환으로 연결합니다. 여러 지역의 독립 씬 전환이 완성된 상태는 아닙니다.

## Progression / Growth

- **영구 캐릭터 레벨**: 포식 완료로 XP를 얻어 기본 체력·공격력이 성장합니다. 귀환·재도전·재접속으로 레벨을 초기화하지 않습니다.
- **골드와 거점 연구**: 일반 적 포식 완료 시 XP와 골드를 함께 저장합니다. 현재 구매 가능한 연구는 포식 범위, 기본 공격, 최대 체력, 블루 A/S/D 강화의 여섯 종류입니다.
- **폼 획득 방향**: 폼을 획득하면 해당 폼의 세 액티브를 모두 제공하고, 기술별 강화는 연구로 진행합니다. 그린·레드는 R2 탐험 단서 발견 후 거점 골드 해금이 설계 방향이며, 실제 R2 단서·해금·폼 변경은 아직 연결하지 않았습니다.
- **변이 방향**: 해금된 패시브를 거점에서 선택하는 빌드 요소로 설계 중입니다. 실제 변이 해금·장착은 미연결이며, 레벨업마다 랜덤 카드를 고르는 흐름을 현재 코어 루프로 소개하지 않습니다.

저장은 독립 RPG 프로필을 사용합니다. 포식 보상과 연구 구매를 원자적 저장(Atomic Save)으로 확정하고, 보상 ID로 중복 지급을 막습니다. 저장 실패 시 진행을 차단하고 재시도를 안내하며, 종료 후에는 전투 중간 상태 대신 확정된 성장과 연구를 유지한 안전한 거점에서 재개합니다.

## Map / Gate / Demonization

| 요소 | 현재 방향과 구현 상태 |
| --- | --- |
| R1 초원 | 일반전·포식·발판 이동·보스·귀환 연구가 연결된 첫 통합 구간. 지형·거점 표현은 시제품 단계 |
| 게이트 / 포털 | 거점 출발 포털과 필드 끝 보스 진입 접점으로 사용. 지역 돌파 조건은 보스 처치 |
| 보스 핵 | 승리 후 수동 포식으로 XP 확정. 미수령 핵은 귀환·재접속 때 거점에서 복원하고, 수령 전 새 도전을 차단 |
| 다음 지역 | R1 클리어와 R2 진행 자격 저장 구현. R2 실제 맵·적·폼 단서는 미구현 |
| 마계화 / 마계 침식 | R1 초원에서 이후 R2~R5로 갈수록 침식이 강해지는 세계관·지역 표현 방향. 동적 침식 수치나 지역 변화 시스템이 구현됐다는 의미는 아님 |

## UI/UX / Presentation

현재 HUD는 체력·레벨·XP·골드·보스 체력·현재 구역·보상/저장 상태를 읽게 하는 기능 시제품입니다. 거점 연구대에서 E로 창을 열고 마우스로 노드 선택·구매, Esc로 닫습니다. 메뉴가 열린 동안 전투 입력을 차단하며, 포커스 복귀 때 눌린 키를 해제하도록 처리합니다.

승인된 꼬리 있는 블루 외형과 피격·레벨업·포식·대기 표정 반응을 통합 씬에 연결했습니다. 보스의 걷기·내려찍기·휩쓸기·뿌리 시전·사망 프레임도 연결했습니다. 모션과 피해 판정의 시점·범위를 맞추고, 배경·전투 지면·장식의 대비를 구분하는 것이 표현 방향입니다.

연구창 최종 디자인, 거점·지형 아트 마감, 신규 VFX와 핵 외형은 후속 작업입니다. 기능 UI와 최종 아트 승인을 구분합니다.

## What Is Implemented Now / Unity 구현 근거

현재 통합 기준은 개발 프로젝트의 `Assets/SideScrollPrototype/Scenes/SideScroll_S6A1_Cycle.unity`입니다. 이동·전투·구역 전환·저장을 실제 컴포넌트로 연결한 씬이며, 아래 파일명은 구현 책임을 설명하기 위한 요약입니다. 소스 전문은 공개하지 않습니다.

| 구현 영역 | 실제 Unity 구성 |
| --- | --- |
| 이동·점프·회피 충돌 | `SideScrollMotor` + `SideScrollStretchAttack` |
| 타격·블루 스킬·수동 포식 | `SideScrollStretchAttack`, `SideScrollSuction` |
| 거점·필드·보스 연결 | `SideScrollHubFlow`, `SideScrollR1Cycle`, `SideScrollBossEncounter` |
| 보스 패턴·핵·지역 자격 | `SideScrollRootWarden`, `SideScrollBossProgression` |
| 영구 성장·보상·연구 저장 | `SideScrollRpgSession`, `RpgProfileStore`, `SideScrollResearchPanel` |
| 데이터·표현 | 전투/포식/연구 CSV, 블루 표정 레이어, 보스 프레임 리소스 |

2026-09-30의 최신 SSOT·진행 기록에는 다음 Unity 검수 결과가 기록되어 있습니다.

- 활성 보스 AI와 정상 수치로 거점 출발 → 일반전·포식 → 발판 이동 → 보스 승리 → 핵 → 귀환 연구 → 강화 재출발의 **입력 루프 14/14 통과**.
- 실제 PlayMode 종료·재시작 후 성장·연구·지역 자격·안전 거점 복원의 **5/5 통과**.
- 직접 상태·저장 장애 주입을 포함한 복귀·저장 회귀의 **25/25 통과**.

이는 개발 기록에 남은 가상 키보드·마우스 입력 및 격리 프로필 검수 결과입니다. 이번 README 갱신에서 Unity를 재실행한 결과나 사람 직접 플레이·배포 빌드 검증을 의미하지 않습니다. 검사 도구와 통합 씬·런타임 코드를 함께 대조했으며, 별도 결과 로그 원문은 공개하지 않습니다.

현행 횡스크롤 통합 구간의 공개 플레이 GIF·영상은 아직 준비되지 않았습니다. 새 캡처를 추가할 때 촬영한 씬과 구현 범위를 함께 표시합니다.
